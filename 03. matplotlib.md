## 1. Why Matplotlib matters

Matplotlib is a Python visualization library. It helps you inspect data and communicate patterns before and after training a Machine Learning or Deep Learning model.

In ML/DL projects, charts help you:

- Understand distributions, ranges, and outliers.
- Find relationships between features.
- Compare groups or categories.
- Check class imbalance.
- Inspect predictions and errors.
- Monitor training and validation loss.
- Present model results clearly.

**Important:** a chart can reveal a pattern, but it does not prove that the pattern is causal or that a model will generalize. Validate conclusions with suitable statistical methods and held-out data.

## 2. Installation and imports

```bash
python -m pip install matplotlib
```

For common data-science work:

Import the plotting interface:

```python
import matplotlib.pyplot as plt
import numpy as np
import pandas as pd
```

`pyplot` (`plt`) provides familiar plotting functions. For reusable or multi-chart figures, prefer the object-oriented style using `fig, ax = plt.subplots()`.

## 3. The basic plotting pattern

```python
import matplotlib.pyplot as plt

x = [1, 2, 3, 4, 5]
y = [2, 4, 3, 7, 8]

fig, ax = plt.subplots(figsize=(7, 4))
ax.plot(x, y, marker="o", label="Measurements")
ax.set_title("Example Line Chart")
ax.set_xlabel("X value")
ax.set_ylabel("Y value")
ax.legend()
ax.grid(True, alpha=0.3)

fig.tight_layout()
plt.show()
```

Main pieces:

- `plt.subplots()` creates a figure (`fig`) and axes (`ax`).
- `ax.plot()` draws a line.
- `set_title()` adds a title.
- `set_xlabel()` and `set_ylabel()` label axes.
- `legend()` explains labeled series.
- `tight_layout()` reduces overlapping labels.
- `show()` displays the figure in a script or supported environment.

## 4. Choose the right chart

| Goal | Useful chart | ML/DL example |
|---|---|---|
| Show a value changing over ordered time | Line chart | Daily traffic, training loss per epoch |
| Compare two numeric variables | Scatter plot | Feature vs. target, actual vs. predicted |
| Compare categories | Bar chart | Number of samples per class |
| Understand a numeric distribution | Histogram | Feature values, prediction errors |
| Compare spread and outliers | Box plot | Feature distribution by class |
| Compare several plots | Subplots | Loss and accuracy side by side |
| Show a matrix of values | Heatmap | Correlation matrix, confusion matrix |
| Show model error distribution | Histogram / scatter plot | Residual analysis |

Choose a chart based on the question, not decoration. Avoid using a line chart for unordered categories because connecting them can imply an order that does not exist.

## 5. Line charts

Use line charts when x-values have a meaningful order, such as time or training epoch.

```python
import matplotlib.pyplot as plt

epochs = [1, 2, 3, 4, 5]
train_loss = [1.2, 0.9, 0.7, 0.55, 0.45]
val_loss = [1.3, 1.0, 0.82, 0.80, 0.88]

fig, ax = plt.subplots(figsize=(7, 4))
ax.plot(epochs, train_loss, marker="o", label="Training loss")
ax.plot(epochs, val_loss, marker="o", label="Validation loss")
ax.set_xlabel("Epoch")
ax.set_ylabel("Loss")
ax.set_title("Training vs. Validation Loss")
ax.legend()
ax.grid(True, alpha=0.3)
fig.tight_layout()
plt.show()
```

Interpretation:
- Both losses decreasing can indicate learning.
- Training loss decreasing while validation loss rises may indicate overfitting.
- A noisy curve is not automatically a problem; inspect trends and validation metrics.

## 6. Scatter plots

Use a scatter plot to inspect relationships between two numeric variables.

```python
import matplotlib.pyplot as plt
import numpy as np

rng = np.random.default_rng(42)
hours_studied = rng.uniform(1, 10, 100)
scores = 10 + 8 * hours_studied + rng.normal(0, 8, 100)

fig, ax = plt.subplots(figsize=(7, 4))
ax.scatter(hours_studied, scores, alpha=0.7)
ax.set_xlabel("Hours studied")
ax.set_ylabel("Score")
ax.set_title("Study Time vs. Score")
ax.grid(True, alpha=0.3)
fig.tight_layout()
plt.show()
```

Scatter plots can reveal trends, clusters, and outliers. Correlation does not by itself establish causation.

### Actual vs. predicted values

For regression, points close to the diagonal line indicate predictions close to actual values.

```python
import matplotlib.pyplot as plt
import numpy as np

y_true = np.array([10, 15, 20, 25, 30])
y_pred = np.array([11, 14, 19, 27, 28])

low = min(y_true.min(), y_pred.min())
high = max(y_true.max(), y_pred.max())

fig, ax = plt.subplots(figsize=(5, 5))
ax.scatter(y_true, y_pred)
ax.plot([low, high], [low, high], linestyle="--", label="Ideal prediction")
ax.set_xlabel("Actual")
ax.set_ylabel("Predicted")
ax.set_title("Actual vs. Predicted")
ax.legend()
ax.grid(True, alpha=0.3)
fig.tight_layout()
plt.show()
```

## 7. Bar charts

Use bars to compare counts or summary values across categories.

```python
import matplotlib.pyplot as plt

classes = ["Cat", "Dog", "Bird"]
counts = [120, 95, 35]

fig, ax = plt.subplots(figsize=(6, 4))
ax.bar(classes, counts)
ax.set_xlabel("Class")
ax.set_ylabel("Number of examples")
ax.set_title("Dataset Class Counts")
fig.tight_layout()
plt.show()
```

This is useful for checking class imbalance. If one class has far fewer examples, accuracy alone may hide poor performance on that class.

## 8. Histograms

A histogram shows how a numeric variable is distributed by grouping values into bins.

```python
import matplotlib.pyplot as plt
import numpy as np

rng = np.random.default_rng(42)
values = rng.normal(loc=50, scale=10, size=1000)

fig, ax = plt.subplots(figsize=(7, 4))
ax.hist(values, bins=30, edgecolor="black")
ax.set_xlabel("Value")
ax.set_ylabel("Frequency")
ax.set_title("Feature Distribution")
fig.tight_layout()
plt.show()
```

Use histograms to check skew, multiple peaks, unusual ranges, and possible outliers. Try a reasonable number of bins; the appearance can change with bin width.

## 9. Box plots

Box plots summarize the median, quartiles, and potential outliers.

```python
import matplotlib.pyplot as plt
import numpy as np

rng = np.random.default_rng(42)
group_a = rng.normal(10, 2, 100)
group_b = rng.normal(13, 3, 100)

fig, ax = plt.subplots(figsize=(6, 4))
ax.boxplot([group_a, group_b], tick_labels=["Group A", "Group B"])
ax.set_ylabel("Measurement")
ax.set_title("Compare Group Distributions")
fig.tight_layout()
plt.show()
```

Box plots are useful for comparing numeric features across classes or groups. A point marked as an outlier is not necessarily a data error; investigate it in context.

> Compatibility note: in older Matplotlib versions, the argument may be named `labels` rather than `tick_labels`. If `tick_labels` raises an error, check your installed version's `boxplot` documentation.

## 10. Subplots and multiple charts

Use subplots to compare related views without opening separate figures.

```python
import matplotlib.pyplot as plt
import numpy as np

rng = np.random.default_rng(7)
values = rng.normal(size=500)

fig, axes = plt.subplots(1, 2, figsize=(10, 4))

axes[0].hist(values, bins=25)
axes[0].set_title("Distribution")
axes[0].set_xlabel("Value")

axes[1].boxplot(values)
axes[1].set_title("Spread and Outliers")
axes[1].set_ylabel("Value")

fig.tight_layout()
plt.show()
```

`axes` is an array of Axes objects when there are multiple subplots. Use `axes[0]`, `axes[1]`, and so on.

## 11. Plotting Pandas data

Matplotlib works well with NumPy arrays and Pandas Series/DataFrames.

```python
import pandas as pd
import matplotlib.pyplot as plt

df = pd.DataFrame({
    "month": ["Jan", "Feb", "Mar", "Apr"],
    "visitors": [120, 180, 160, 240],
    "signups": [12, 22, 18, 35],
})

fig, ax = plt.subplots(figsize=(7, 4))
ax.plot(df["month"], df["visitors"], marker="o", label="Visitors")
ax.plot(df["month"], df["signups"], marker="o", label="Signups")
ax.set_xlabel("Month")
ax.set_ylabel("Count")
ax.set_title("Visitors and Signups")
ax.legend()
fig.tight_layout()
plt.show()
```

For a DataFrame, `.plot()` can also be convenient:

```python
df.plot(x="month", y=["visitors", "signups"], marker="o")
plt.tight_layout()
plt.show()
```

Use the direct Matplotlib API when you need detailed control over axes, labels, annotations, or multiple plot types.

## 12. Visualizing ML model performance

### 12.1 Compare model metrics

```python
import matplotlib.pyplot as plt

models = ["Logistic Regression", "Random Forest", "MLP"]
accuracy = [0.84, 0.89, 0.87]

fig, ax = plt.subplots(figsize=(7, 4))
ax.bar(models, accuracy)
ax.set_ylim(0, 1)
ax.set_ylabel("Accuracy")
ax.set_title("Model Comparison")
fig.tight_layout()
plt.show()
```

Compare models using the same data split and evaluation protocol. If classes are imbalanced, also examine precision, recall, F1, and a confusion matrix.

### 12.2 Residual plot for regression

A residual is `actual - predicted`. Plotting residuals can reveal systematic errors.

```python
import matplotlib.pyplot as plt
import numpy as np

y_true = np.array([10, 15, 20, 25, 30, 35])
y_pred = np.array([12, 14, 18, 28, 27, 36])
residuals = y_true - y_pred

fig, ax = plt.subplots(figsize=(7, 4))
ax.scatter(y_pred, residuals)
ax.axhline(0, linestyle="--")
ax.set_xlabel("Predicted value")
ax.set_ylabel("Residual (actual - predicted)")
ax.set_title("Residual Plot")
ax.grid(True, alpha=0.3)
fig.tight_layout()
plt.show()
```

Patterns in residuals can suggest bias, nonlinearity, or changing error variance. Random-looking residuals are generally more reassuring, but they do not prove that a model is correct.

## 13. Visualizing Deep Learning training

Keras `model.fit()` returns a `History` object containing metrics recorded during training.

```python
# After training:
# history = model.fit(...)

import matplotlib.pyplot as plt

fig, axes = plt.subplots(1, 2, figsize=(11, 4))

axes[0].plot(history.history["loss"], label="Training")
if "val_loss" in history.history:
    axes[0].plot(history.history["val_loss"], label="Validation")
axes[0].set_title("Loss by Epoch")
axes[0].set_xlabel("Epoch")
axes[0].set_ylabel("Loss")
axes[0].legend()

metric_name = "accuracy"
if metric_name in history.history:
    axes[1].plot(history.history[metric_name], label="Training")
if f"val_{metric_name}" in history.history:
    axes[1].plot(history.history[f"val_{metric_name}"], label="Validation")
axes[1].set_title("Accuracy by Epoch")
axes[1].set_xlabel("Epoch")
axes[1].set_ylabel("Accuracy")
axes[1].legend()

fig.tight_layout()
plt.show()
```

The available metric keys depend on what was passed to `model.compile()`. For a PyTorch training loop, store loss/metric values in lists during each epoch and plot those lists the same way.

## 14. Heatmaps and confusion matrices

Matplotlib can display a matrix with `imshow`. For a confusion matrix, calculate the values using a metric library, then visualize them.

```python
import matplotlib.pyplot as plt
import numpy as np
from sklearn.metrics import confusion_matrix

y_true = [0, 1, 2, 1, 0, 2, 2, 1]
y_pred = [0, 2, 2, 1, 0, 1, 2, 1]
cm = confusion_matrix(y_true, y_pred)

fig, ax = plt.subplots(figsize=(5, 4))
image = ax.imshow(cm, interpolation="nearest")
fig.colorbar(image, ax=ax, label="Count")
ax.set_xlabel("Predicted class")
ax.set_ylabel("True class")
ax.set_title("Confusion Matrix")

for row in range(cm.shape[0]):
    for col in range(cm.shape[1]):
        ax.text(col, row, str(cm[row, col]), ha="center", va="center")

fig.tight_layout()
plt.show()
```

Rows represent true classes and columns represent predicted classes in the default scikit-learn confusion matrix. Check class ordering if labels are not numeric or if you supply an explicit label order.

### Correlation heatmap

```python
import matplotlib.pyplot as plt
import pandas as pd

df = pd.DataFrame({
    "age": [20, 25, 30, 35, 40],
    "income": [25, 32, 40, 47, 55],
    "score": [70, 68, 80, 85, 82],
})

corr = df.corr(numeric_only=True)

fig, ax = plt.subplots(figsize=(5, 4))
image = ax.imshow(corr, vmin=-1, vmax=1, cmap="coolwarm")
fig.colorbar(image, ax=ax, label="Correlation")
ax.set_xticks(range(len(corr.columns)), labels=corr.columns, rotation=45, ha="right")
ax.set_yticks(range(len(corr.index)), labels=corr.index)

for row in range(len(corr.index)):
    for col in range(len(corr.columns)):
        ax.text(col, row, f"{corr.iloc[row, col]:.2f}", ha="center", va="center")

ax.set_title("Feature Correlation")
fig.tight_layout()
plt.show()
```

Correlation can help identify related features, but it does not establish causation. A high correlation also does not automatically mean a feature should be removed.

## 15. Labels, legends, styles, and readability

Useful settings:

```python
fig, ax = plt.subplots(figsize=(8, 4))
ax.plot([1, 2, 3], [3, 5, 4], marker="o", label="Series A")
ax.set_title("Readable Chart")
ax.set_xlabel("Time")
ax.set_ylabel("Value")
ax.legend()
ax.grid(True, alpha=0.25)
fig.tight_layout()
plt.show()
```

Good chart practices:

- Use a title that describes the question.
- Label axes and include units when relevant.
- Use legends only when multiple series need explanation.
- Keep tick labels readable.
- Use a suitable figure size.
- Avoid unnecessary 3D charts and visual decoration.
- Do not truncate axes in a way that exaggerates differences.
- Use color palettes that remain understandable for people with color-vision deficiencies.
- Add units, sample size, or context when they affect interpretation.

## 16. Save a chart

```python
fig, ax = plt.subplots(figsize=(7, 4))
ax.plot([1, 2, 3], [2, 4, 3])
ax.set_title("Saved Figure")
fig.tight_layout()

fig.savefig("chart.png", dpi=200, bbox_inches="tight")
fig.savefig("chart.pdf", bbox_inches="tight")
plt.close(fig)
```

- PNG: useful for web pages and documents.
- PDF/SVG: useful for vector output when supported by the target application.
- `dpi`: controls raster resolution.
- `bbox_inches="tight"` helps avoid clipping labels.
- `plt.close(fig)` releases the figure when generating many charts in scripts.

Save the figure before closing it.

## 17. Common mistakes

1. Forgetting axis labels or units.
2. Using line charts for unordered categories.
3. Comparing models that were evaluated on different splits.
4. Reading training accuracy without checking validation/test performance.
5. Assuming correlation proves causation.
6. Making charts too crowded with too many colors or labels.
7. Forgetting `tight_layout()` and clipping text.
8. Calling `plt.show()` before saving in workflows where the figure may be cleared or closed.
9. Treating every statistical outlier as an invalid record.
10. Using a confusing color scale for a heatmap.
11. Forgetting that chart patterns depend on scale, bins, and sampling.

## Recommended learning order

1. Learn `fig, ax = plt.subplots()`.
2. Practice line, scatter, bar, and histogram charts.
3. Explore distributions and outliers before training a model.
4. Plot actual vs. predicted values and regression residuals.
5. Plot training/validation loss and metrics.
6. Visualize confusion matrices and feature correlations.
7. Save clean figures for reports, documentation, and dashboards.

**Final principle:** visualization is part of the ML workflow—not just presentation. Plot your data before training, and plot model errors after training.
